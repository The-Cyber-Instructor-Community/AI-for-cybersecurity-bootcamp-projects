5-Phase Workflow

🔍 Phase 1 — Passive Reconwhois · dns_recon (PTR/MX/zone transfer) · theHarvester OSINT — no packets to target
📡 Phase 2 — Active Scannmap (service/version) · nikto (web) · gobuster (dirs) · enum4linux (SMB) + Kali MCP: hydra · sqlmap · masscan · ffuf
🧠 Phase 3 — Intelligencesearchsploit → CVE RAG lookup → fine-tuned Llama 3.1 8B analysis → ATT&CK TTP mapping
⚔️ Phase 4 — Exploitation  (suggest only — never auto-executes)Metasploit RPC → stage modules → map to open ports → confirm root shell paths
📋 Phase 5 — ReportMarkdown + HTML dashboard · remediation playbooks · CVSS scores · ATT&CK mapping → reports/
