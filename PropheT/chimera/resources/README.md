# Resources

- `disposable_email_blocklist.conf`: disposable and temporary email domains, one per line, from
  https://github.com/disposable-email-domains/disposable-email-domains (CC0 1.0, public domain dedication),
  downloaded 2026-10-18 (9,901 domains). Used by `chimera/lookups.py`. The project notes: "We cannot guarantee
  all of these can still be considered disposable", so a match is moderate evidence, never strong.
