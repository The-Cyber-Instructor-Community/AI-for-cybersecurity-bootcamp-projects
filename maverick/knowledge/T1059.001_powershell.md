# T1059.001 Command and Scripting Interpreter: PowerShell

## What it looks like
PowerShell runs with an encoded command (-enc / -EncodedCommand), often hidden (-w hidden) and without a profile (-nop).

## Signals that point to malicious
- Parent process is an email client, browser or Office application.
- Runs shortly after an external link click by the same user.
- Hidden window and encoded command together.

## Signals that point to benign
- Parent is a developer tool or IDE (for example VS Code) on a developer's workstation.
- Known build or admin tooling with a change record.

## Triage guidance
The parent process is the most useful single field. Outlook or a browser spawning encoded PowerShell should be escalated.
