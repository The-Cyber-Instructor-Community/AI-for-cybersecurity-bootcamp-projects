# T1078.004 Valid Accounts: Cloud Accounts

## What it looks like
A successful sign-in to a cloud service with real credentials, but from a device or location new to that user.

## Signals that point to malicious
- New device and new country together, with no travel notice.
- Sign-in source IP that later reads cloud data in bulk.
- Sign-in shortly after the user clicked an external link.

## Signals that point to benign
- Approved travel notice for the user.
- New device in the usual country, with no other suspicious activity (often a laptop refresh).

## Triage guidance
On its own a new-device sign-in is common. Correlate the source IP with later cloud activity before deciding.
