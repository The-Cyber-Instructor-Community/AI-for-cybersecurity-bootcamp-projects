# T1566.002 Phishing: Spearphishing Link

## What it looks like
An email from outside the organisation carries a link, and the user clicks it. The link usually leads to a fake login page or a payload download.

## Signals that point to malicious
- Sender domain registered recently (days or weeks old).
- Urgent lure: invoices, payroll, mailbox quota, shared bonus documents.
- Link domain does not match the claimed sender organisation.
- Follow-on activity from the same user soon after the click: new-device sign-in, encoded PowerShell, discovery commands.

## Signals that point to benign
- Long-registered sender domain the organisation already receives mail from, such as a newsletter.
- No follow-on activity from the same user after the click.

## Triage guidance
A click alone is weak evidence. Escalate when the domain is new or when any follow-on stage appears. Remember a long-registered site can still be compromised, so check for missing telemetry before closing.
